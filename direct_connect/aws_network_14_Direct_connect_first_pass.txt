DX gateway => multiple VPCs over same DX connection
- DX directly to VPCs -> Private VIF in each VPC in same region. Each with BGP session.
- DX gateway to multiple VPCs -> one private VIF from DX to DXG, possibly multiple regions.
- DXG is also private, cannot access public.
- DXG and Private VIF in same account, but VPCs can be in other accounts.
- DXG does not allow VPC-VPC (only for on-prem data center I guess). Unlike TGW.
- Max 100 routes for each IPv4 and IPv6.
- DXG can connect to up to 20 VPCs (VGWs)
- Multiple DXG with separate private VIFs to increase 20 VPC limit (20 VPC per DXG)
- Multiple DX with separate private VIFs to one DXG for global data centers. But still VPCs can't contact each other.
-- Also Data Centers can't communicate with each other through DXG
- no charge for DXG, but egress traffic is charged
